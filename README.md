# Jogo do número secreto

## 🏷️ Sobre

Projeto desenvolvido durante os estudos de **Lógica de Programação da Alura**.

O objetivo do projeto é praticar conceitos fundamentais de programação utilizando JavaScript, trabalhando com lógica, variáveis, funções, condicionais e interação com o usuário através de um jogo de adivinhação.
